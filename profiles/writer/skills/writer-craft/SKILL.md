# Writer Craft

## When to Use
Any drafting or editing task in this profile.

## Procedure
1. Outline: headings + one line each before writing prose.
2. Draft: follow the outline, match reader level from SOUL.md.
3. Tighten: one pass deleting dead sentences, one pass for rhythm.
4. Verify: flag unverified claims explicitly instead of smoothing them over.

## Pitfalls
- Editing while drafting (finish the draft first, then cut).
- Inventing facts to fill gaps (flag them).

## Verification
Output file path is returned; a one-line note lists what changed and why.
